Fontes de pesquisa: peças automotivas por marca

Como usar esta página

Este é um índice de fontes para pesquisa de peças automotivas (originais e genuínas) das marcas Volkswagen, Fiat, Chevrolet, Mitsubishi, Hyundai, JAC, Ford e BMW.

  • Identifique a marca do veículo e consulte as fontes listadas nessa marca.
  • Lojas nacionais (Brasil): use para preço, disponibilidade e compra no mercado brasileiro.
  • Catálogos internacionais (7zap, PartSouq, RealOEM, OEM Parts Online): use para identificar o código original (OEM/part number) da peça por modelo, ano ou chassi (VIN). Depois, use o código para buscar nas lojas nacionais.
  • Sempre que possível, cruze o código da peça entre duas ou mais fontes antes de confirmar.

Volkswagen (VW)

  • Loja Virtual Volkswagen (Peças e Acessórios Originais): loja oficial brasileira de peças e acessórios originais VW.
  • 7zap: catálogo Volkswagen (ETKA Online, Europa): catálogo de peças OEM, busca por VIN e parâmetros. Útil para achar o código original.
